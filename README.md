# 🪪 Cartão de Visitas Digital | Personal Profile Card

Um cartão de visitas digital interativo e bilíngue (Português/Inglês) desenvolvido para apresentar meu portfólio, redes sociais e formação acadêmica de forma direta e moderna.

## ✨ Funcionalidades

- **Animação 3D (Flip):** O cartão gira no próprio eixo para exibir o verso com informações de formação e tecnologias.
- **Internacionalização (i18n):** Troca de idioma em tempo real (PT/EN) sem recarregar a página.
- **Memória de Idioma:** Utiliza `localStorage` para lembrar a preferência de idioma do recrutador/visitante.
- **Design Responsivo:** Layout fluido e adaptado para visualização limpa tanto em mobile quanto em desktop (sem barras de rolagem desnecessárias).

## 🚀 Tecnologias Utilizadas

- **HTML5:** Semântica e estrutura.
- **CSS3:** Variáveis CSS, Flexbox, efeitos de Perspectiva 3D (`transform-style: preserve-3d`) e transições.
- **JavaScript (Vanilla):** Manipulação do DOM e gestão de estado (i18n + LocalStorage).
- **FontAwesome:** Ícones das redes sociais.
- **FlagCDN:** Renderização limpa de SVG para as bandeiras de idiomas.
